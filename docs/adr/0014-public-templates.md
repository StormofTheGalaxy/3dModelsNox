# ADR 0014 — Публичные шаблоны ТЗ (post-MVP №6)

Дата: 18.08.2026 · Статус: принято

Шестой пункт списка post-MVP из ТЗ §7. В §4.4 шаблоны уже описаны:
девять системных пресетов из сида и «Сохранить как мой шаблон» — личные.
Post-MVP добавляет третье состояние: личный шаблон, открытый для всех.

Модуль за флагом `feature_public_templates`, по умолчанию выключенным.

---

## 1. Три состояния, а не два

`isSystem` — заготовка платформы, живёт в сиде, ключи подписей i18n.
`isPublic` — личный шаблон, открытый автором.
Всё остальное — личное.

Системные пресеты публичны по определению и флага не требуют: они
принадлежат платформе, и трогать их публикацией или снятием нельзя ни
автору, ни модератору.

## 2. Системные всегда впереди

Каталог сортируется по популярности или новизне, но системные пресеты
идут первыми независимо от сортировки.

Это проверенные заготовки, с которых начинают. Задвинуть их за чей-то
популярный шаблон значит поменять смысл списка: человек, впервые
открывший каталог, должен увидеть сначала то, за что отвечает платформа.

## 3. Свои применения не считаются

`usesCount` растёт, только когда шаблон берёт кто-то другой. Иначе автор
накручивает себе место в каталоге, создавая ТЗ по собственному шаблону.

## 4. Снятие модератором необратимо автором

Модератор ставит `hiddenAt` и снимает `isPublic`. У автора шаблон
остаётся личным — им можно пользоваться, но кнопки «опубликовать» больше
нет.

Иначе кнопка публикации отменяет решение модерации, и снятие превращается
в предложение, а не в решение. Вернуть шаблон в каталог может только тот,
кто его снял, — из базы или из будущего раздела жалоб.

## 5. Дата публикации не переписывается

Повторная публикация после самостоятельного снятия сохраняет первую
`publishedAt`: по ней сортируется «новое», и шаблон должен быть новым
один раз, а не всякий раз, когда автор передумал.

## 6. Тип ассета считается из секций, а не хранится колонкой

Фильтр каталога читает `sections.general.assetType`. Денормализовать его
ради одного экрана не стоит: шаблонов десятки, а не тысячи, и лишняя
колонка — это лишняя рассинхронизация при правке шаблона.

## 7. Каталог только для вошедших

Шаблон нужен, чтобы создать ТЗ, а создать его может только подтверждённый
аккаунт. Гостю здесь показывать нечего, кроме списка, по которому он не
может ничего сделать; при выключенном флаге страница отдаёт 404.

## 8. Что осталось за рамками

- **Премодерации публикации нет.** Шаблон появляется в каталоге сразу,
  как и работы (§4.3: «работы не проходят премодерацию»). Разбирается
  постфактум — жалобой и снятием.
- **Форк чужого шаблона в свой не делается.** «Взять за основу» создаёт
  ТЗ; чтобы получить из него свой шаблон, есть обычное «Сохранить как мой
  шаблон» на этом ТЗ. Отдельная кнопка «скопировать шаблон» была бы вторым
  путём к тому же результату.
- **Описание шаблона задаётся только правкой.** Диалог «Сохранить как мой
  шаблон» просит одно название — добавлять в него второе поле ради
  необязательного текста значит удлинять шаг, который делают мимоходом.
