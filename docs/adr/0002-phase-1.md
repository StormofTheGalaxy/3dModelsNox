# ADR-0002. Решения фазы 1

Дата: 2026-08-17 · Статус: принято

Профили, портфолио и галерея. Решения, которые не следуют напрямую из ТЗ.

---

## 1. Файлы идут через приложение, а не по подписанной ссылке в S3

**Решение:** загрузка — обычный `POST` в server action, оттуда поток уходит в
хранилище через `@polyforge/storage`.

**Почему:** при прямой загрузке в S3 по presigned URL сервер не видит файла и
не может проверить тип, размер и права до того, как объект окажется в бакете —
остаётся сверять постфактум и подчищать мусор. Прогон через приложение даёт одну
точку проверки и один и тот же код для прода и разработки.

Плата — трафик видео (до 200 МБ) через контейнер `app`. Для беты приемлемо;
если упрёмся, переход на presigned URL меняет только `storeWorkMedia`.

## 2. Абстракция хранилища с локальным драйвером

`packages/storage` даёт интерфейс `StorageProvider` и две реализации: S3 и диск.

**Почему:** ТЗ называет Timeweb S3, но поднимать S3-совместимое хранилище ради
локальной разработки — лишний барьер для входа в проект. Драйвер выбирается
переменной `STORAGE_DRIVER`, интерфейс один, и прод-путь при этом остаётся
единственным боевым.

**Ограничение:** в проде локальный драйвер использовать нельзя — `app` и
`worker` живут в разных контейнерах и не делят файловую систему. Это записано
в README.

## 3. Оригинал изображения остаётся в хранилище

Воркер делает две производные (`display` 1600px и `thumb` 640px в webp) и не
удаляет исходник.

**Почему:** размеры превью — продуктовое решение, которое ещё будет меняться.
Без оригинала пересобрать их будет не из чего. Наружу отдаются только webp,
оригинал никуда не публикуется.

## 4. Работа создаётся черновиком до заполнения формы

`/works/new` создаёт пустую запись со скрытым флагом и сразу редиректит на
маршрут правки.

**Почему:** загруженным файлам нужен владелец в базе — иначе пришлось бы
держать «ничьи» медиа и подчищать их по таймауту. Черновик отличается пустым
заголовком и `isHidden: true`, поэтому в выдачу он не попадает, а повторный
заход на `/works/new` переиспользует незавершённый черновик вместо создания
нового.

## 5. Счётчик просмотров — в Redis, без таблицы

Дедупликация по ключу `view:work:<id>:<зритель>` с TTL в сутки, инкремент
денормализованного поля `views`.

**Почему:** таблица просмотров на галерее — это миллионы строк ради числа под
картинкой. Точность здесь не нужна. Если Redis недоступен, просмотр не
засчитывается вовсе: недосчитать честнее, чем накрутить.

## 6. Лайки меняют денормализованный счётчик в транзакции

`WorkLike` и `PortfolioWork.likesCount` обновляются одной транзакцией.

**Почему:** сортировка галереи по популярности читает `likesCount`; считать
`COUNT(*)` на каждой выдаче — лишняя работа. Транзакция не даёт счётчику
разъехаться с таблицей лайков при двойном клике.

## 7. Ник в фильтрах и состояние галереи — в URL

Фильтры каталога и галереи живут в query-параметрах, а не в React-состоянии.
Смена фильтров перемонтирует список через `key`.

**Почему:** ссылку на подборку можно отправить, кнопка «назад» работает
ожидаемо, а SSR отдаёт уже отфильтрованный первый экран — это же важно для SEO.

## 8. Значения фильтров сверяются со справочником на сервере

`isOneOf()` в каталоге и zod-схема в галерее.

**Почему:** параметры приходят из URL, то есть от пользователя. Без сверки они
уехали бы в `where` Prisma как есть — на enum-полях это ошибка запроса, а на
строковых открывает лишнюю поверхность.

## 9. Тег-инпуты вместо закрытых списков софта и движков

Софт, движки и форматы — свободный ввод с подсказками-пресетами.

**Почему:** список 3D-софта не закрыт, и «моего инструмента тут нет» — плохой
первый экран для дизайнера. Пресеты покрывают типичный выбор, остальное
дописывается руками; в базе это `String[]`.

## 10. Обход лимита на регистрацию в тестах — не послабление в продукте

Сквозной тест сбрасывает ключи `rl:register:*` перед прогоном.

**Почему:** все запросы теста идут с одного адреса, и лимит (5 регистраций в
час на IP) справедливо срабатывает на втором пользователе. Ослаблять лимит ради
теста было бы неправильно — сбрасывается счётчик, а не порог.
